# 对人民币

一次看完常用外币兑人民币的价格和趋势。给每天要查很多货币对、又不想一个网页一个网页刷新的人用。

这是一个网页应用，不是需要开发者证书的 iPhone App。iPhone 17 和 Mac 都能用，也不用每 7 天重新签名。

## 为什么不用原生 iPhone App

免费 Apple 开发者证书装到手机上，大约 7 天就会失效。付费账号可以长期装，但为了「每天看几个汇率」不值得。

系统状态栏也不能让第三方 App 常驻数字。

所以更省事的做法是：做一个单页看板，Safari 打开后「添加到主屏幕」或「添加到程序坞」，用起来像 App。

## 能做什么

- 默认一次显示美元、欧元、日元、英镑、港币等 12 个常见货币对人民币
- 每个货币对带现价、涨跌幅和 7 / 30 / 90 日走势
- 日元、韩元按 100 计价，印尼盾、越南盾按 10000 计价，和国内看牌习惯接近
- 点开卡片看该货币的区间高低
- 可自己勾选要看的货币，只存在你这台设备上

数据来自 [Frankfurter](https://www.frankfurter.app/docs/) 汇总的各国央行参考价，每个工作日更新。适合看趋势，不是交易下单用的实时成交价。

## 在 iPhone 17 上用

页面发布后，用 Safari 打开，不要用微信或 Chrome 内置浏览器。

1. 点底部分享按钮
2. 选「添加到主屏幕」
3. 以后从图标进去，就是一页看完全部汇率

下拉页面可以刷新。

## 在 Mac 上用

Safari 打开同一地址后：

- 菜单栏选「文件」→「添加到程序坞」，或
- 直接把标签页留着，当每日看板

本地预览：

```bash
python3 -m http.server 8080 --directory docs
```

然后打开 http://127.0.0.1:8080

## 发布成自己能打开的网址

把仓库的 GitHub Pages 指到 `docs/` 目录即可，地址一般是：

`https://<你的用户名>.github.io/JobsRSS/`

仓库设置路径：Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/docs`。
